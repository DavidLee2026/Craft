# 每日绘 Craft 🖊️✨

AI 陪伴式绘画 App——只需要一张纸和一支笔就可以开始。

手机拍下纸上的画，AI 逐层给出反馈，见证你的每天进步。

## 快速开始

```bash
pip install -r requirements.txt
# 在 .env 中配置 API Key（参考 .env 文件格式）
python3 app.py
```

手机连接同 Wi-Fi，浏览器访问终端显示的地址。

## 功能

### 绘画反馈
- **5 层流式反馈** 🧠：认出内容 → 具体观察 → 进步连接 → 技巧建议 → 鼓励期待，逐层在屏幕上出现
- **自适应深度学习** 📈：根据用户绘画张数自动调节语言难度（新手禁用术语 → 熟练引用大师对比）
- **应用内相机** 📸：拍照即反馈，支持前后摄像头切换
- **每日主题** 🎯：每天一个推荐绘画主题，解决"画什么"的空白焦虑
- **等待陪伴动画** ⏳：AI 处理时逐句文案填充空白，不是转圈圈

### 成长系统
- **里程碑成就** 🏆：第 1/5/10/25/50 张触发专属庆祝卡片
- **时间线记录** 📖：所有画作时间轴，弹窗查看大图+完整反馈
- **连胜打卡** 🔥：连续绘画天数追踪
- **成长关卡** 🌱：400 关渐进式练习体系（含 Boss 挑战）

### 交互增强
- **术语弹窗** 📚：绘画专业术语点击可查看"在你这幅画里"的具体解释
- **反思交互** ✍️：AI 反问"最满意的地方是哪里？"，形成小对话
- **延迟操作按钮** ⏱：反馈后 2s 再出现选项，给用户消化鼓励的时间
- **主题库** 🎨：易/中/难三段难度，自由切换当前主题
- **大师图库** 🖼️：经典作品参考，搜素与浏览

### PWA 支持
- 支持添加到主屏幕，离线可用
- Service Worker 智能缓存策略

## 技术栈

- 后端：Flask + LLM API（视觉语言模型）
- 前端：纯 HTML + CSS + JavaScript（无框架）
- 流式反馈：Server-Sent Events (SSE)
- 数据：本地 JSON 文件存储
- 离线：Service Worker + Cache API

```
│   └── sw.js               # Service Worker

```
